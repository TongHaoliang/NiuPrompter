# NiuPrompter · 牛哥提词器

**NiuPrompter（牛哥提词器）：一个跟着你说话走的中文提词器。**

在 GitHub 搜索 **niuprompter**，或直接打开 [TongHaoliang/NiuPrompter](https://github.com/TongHaoliang/NiuPrompter)。支持 iPhone 提词拍摄、iPad 镜像提词、本地语音智能跟随；附可复制的 AI 开发提示词。

A voice-following teleprompter for iPhone and iPad, with on-device speech recognition, camera recording, and a script library.

口播时，最打断节奏的事之一，就是你还没说完，稿子已经滚走了；或者你已经说完，却还得等下一句。

我给自己做了这个小工具：把稿件放进去，它会听你正在说什么，找到对应的位置。快念完一句时，提前把下一句亮出来，让眼睛先接上，嘴巴继续把句尾说完。

手机默认边拍边提词；iPad 保留适合远距离阅读的纯提词界面。

## 用起来是什么感觉？

- **按你的节奏来。** 不是设置一个固定速度一直滚，而是根据实际朗读跟随。
- **下一句提前准备好。** 在识别到句尾位置后提前提示，减少念完一句还要等画面的停顿。
- **允许临时发挥。** 中间插几句自己的话，画面先保留位置；说回稿件后，再尝试找到你的位置。
- **当前句醒目，后文也能看清。** 字号、左右留白都能调，配合提词器反射镜时可以开启镜像。
- **手机直接拍口播。** 全屏看到自己，透明稿件靠近镜头，点录像自动跟随；需要配合独立相机时，可切到纯提词模式。

编辑稿件时，还会显示字数和预计朗读时长，方便判断这一段大概要讲多久。

## 你可以选两种方式

### 想自己做一个类似的

复制[这段提示词](docs/RECREATE_PROMPT.md)，交给能创建工程、运行代码的AI编程工具。不用下载这个项目，也不需要拿到我的聊天记录；它描述的是要做什么、怎么跟随、界面怎么摆。

不同AI、设备和实现会有差异，可以先做一个相近版本，再按自己的口播习惯调整。

### 想用我已经调过的版本

你可以先看这个仓库的代码和界面，再让AI或开发者按[安装与开发文档](docs/DEVELOPMENT.md)帮你构建。

**目前提供的是源码，不是App Store下载。** 自行安装需要Mac、Xcode、自己的Apple账号，以及支持本地中文识别的iPhone/iPad。首次使用可能需要下载系统语音模型。

装好后的使用步骤：

1. iPhone 打开即进入拍摄预览，允许相机和麦克风。从左上角“稿件”新建或选择一篇。
2. 调整悬浮文字字号、亮度和位置，点红色录像按钮，智能跟随自动开启。
3. 想重念时滚回前文，点击目标句再继续说；不用停止录像。
4. 录完进入“视频”，可回看、导出、存入相册或删除本机副本。

纯提词模式收在拍摄设置里，提供字号、边距和镜像。iPad 默认纯提词，选稿后点击开始跟随。

## 先说清楚几个边界

它是我实际口播中逐步调整的小工具，还不是所有场景都打磨完的产品。环境噪声、相似句子、临时大幅改写和系统识别延迟，都可能影响跟随；你也可以用上下句按钮手动调整。

- 语音识别在设备本机进行，应用没有接入第三方云识别服务。普通提词不保存录音；iPhone 拍摄模式仅在点击录像后保存含声音的视频到本机。
- **稿件库和每篇阅读位置自动保存在本机**，重开后可继续；字号、边距和镜像设置也会记住。卸载应用会丢失本机数据，请另留重要原稿。保存失败时会明确提示。
- 预计时长按每分钟250字粗估，不是测量你的个人语速。
- 免费Apple开发签名有有效期，到期需要重新构建安装，具体见开发文档。

```sh

open SmartTeleprompterProbe-iPadProject.xcodeproj
```

验证改动：

swift run --disable-sandbox TeleprompterChecks

### iPhone 边拍边提词（试用）
iPhone 打开后默认进入前置提词拍摄，左上角“稿件”可进入稿件库选稿或编辑。纯提词模式位于拍摄设置内，返回拍摄点击摄像机按钮。全屏可看到自己，透明提词靠近镜头，可拖动并调整字号和透明度。点击红色按钮开始录像后自动开启智能跟随，结束录像时停止跟随；录制中仍可单独暂停或恢复跟随。视频不包含提词文字或操作按钮；预览镜像，成片为正常方向。横竖屏均支持，单条视频方向按开始时锁定。

视频先存本机，在“视频”中回看、分享或主动存入相册。退出拍摄或切后台会结束录像；卸载应用会删除尚未导出的本机视频。首次进入需允许相机、麦克风，存相册时才申请相册添加权限。

本机视频支持点击“删除视频”或左滑删除，经确认后仅移除 App 内副本，不影响系统相册和已导出的文件。

### 稿件库
手机拍摄页左上角“稿件”进入稿件库。可新建、编辑、重命名、删除多篇稿件，显示字数与预计时长；点选一篇直接返回拍摄。每篇分别自动保存正文和阅读位置，当前稿件标记“使用中”。旧版的单篇稿件会自动迁入。数据仅在本机，卸载会清除。
